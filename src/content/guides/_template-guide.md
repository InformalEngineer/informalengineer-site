Guide template (02-PRD §6, styleguide format B). Enforced structure:

1. Answer-first summary (frontmatter `summary`, rendered as the top box)
2. Tested-on block (frontmatter, rendered as header block)
3. BOM table where physical (frontmatter)
4. Numbered procedure with checkpoints ("you should now see…")
5. Failure modes encountered (mandatory, honesty is the brand)
6. Cost summary
7. Changelog (frontmatter)
8. Exactly one CTA

Titling: outcomes with numbers ("Build a 48TB NAS for $300 with used SAS
drives"). No unearned superlatives. Voice: styleguide_mesh_v3, tutorial rules
(answer first, hardest step early and named, real time stated if it took longer).
